    Sobre el mapa: es un mapa esquemático (no callejero) para ver el orden de la ruta y dónde duermen; los botones de arriba acercan cada zona. Los km de cada día se calcularon por carretera y se pueden corregir en el itinerario. Para navegar, usen el enlace a Google Maps de cada día. Sobre compartir esta página: el viaje se guarda en esta misma página de Claude y se sincroniza en vivo con quien pueda abrirla. Usen el botón «Compartir» de Claude (arriba de la página, fuera de este cuaderno) para mandar el link a quien viaja con ustedes; con acceso «puede editar» también podrá añadir paradas y gastos. Sobre exportar a GitHub: «Exportar HTML (GitHub)» descarga una copia independiente de esta página, con el viaje actual adentro, que funciona sola (sin Claude) con solo abrir el archivo o subiéndola a un repositorio con GitHub Pages. Esa copia guarda los cambios solo en el navegador de quien la abra; para compartir la versión más reciente, exporten de nuevo.
